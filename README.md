# 错题白卷生成器（Windows 版）

拍试卷 → 拖动鼠标框选错题 → 保真擦除手写 → 拼成 A4 白卷 PDF，打印让孩子重练。

## 一、准备：腾讯云密钥（只需一次）

1. 打开 https://console.cloud.tencent.com/ocr ，注册/登录并**开通"文字识别 OCR"服务**（新用户有每月 1000 次免费额度）。
2. 打开 https://console.cloud.tencent.com/cam/capi ，创建密钥，得到 **SecretId** 和 **SecretKey**。
3. 将 `config.local.example.json` 复制为 `config.local.json`，填入新密钥。也可设置环境变量 `TENCENTCLOUD_SECRET_ID` 和 `TENCENTCLOUD_SECRET_KEY`（优先于本地配置）。不要分享 `config.local.json`；该文件已加入 Git 忽略列表，但手动打包时仍需排除。原配置中曾保存的密钥应在腾讯云控制台轮换。

## 二、启动（双击即可）

双击 **`启动工具.bat`**。
- 首次运行会自动创建虚拟环境并安装依赖（需要联网，约 2~5 分钟，只需一次）。
- 之后每次双击都会直接启动，浏览器自动打开 `http://127.0.0.1:7860`。

## 三、使用

1. 上传试卷照片（支持点击选择 / 直接拖入 / 截图粘贴；手机照片可用微信"文件传输助手"发到电脑后保存再拖入）。
2. **按住鼠标左键拖出一个框**，框住一道错题；可框多道题；**双击某个框可删除**，右侧按钮可"撤销最后一框 / 清空全部"。
   - 如果黑色铅笔或签字笔答案没有自动擦掉，点 **“手动擦除答案”**，用橙色框只圈住残留笔迹；生成时该区域会直接留白。切回题目框选模式可继续添加题目。
3. 点 **"生成错题白卷"**。
4. 右侧预览白卷，点 **"下载 A4 白卷 PDF"** 保存，打印即可。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 提示"密钥尚未填写" | 检查环境变量或 `config.local.json`，更新后重启工具 |
| 提示"处理失败：FailedOperation..." | 检查网络；密钥是否有 OCR 权限；图片是否过小/模糊 |
| 想用手机拍照直接传 | 手机和电脑连同一 Wi-Fi，电脑浏览器开 `http://127.0.0.1:7860` 即可在手机浏览器访问同一地址（需将 app.py 中 launch 改为 `server_name="0.0.0.0"`） |
| 想整卷擦除（不留原题） | 拖一个框把整张卷子框住即可；或后续版本提供"整卷擦除"按钮 |

## 五、文件说明

- `app.py` —— 主程序（Flask 后端：接收框选坐标 → 腾讯云擦除 → A4 拼卷）
- `templates/index.html` —— 前端页面（拖框选择界面）
- `config.json` —— 可共享的处理参数
- `config.local.json` —— 仅本机保存的密钥，禁止分享
- `requirements.txt` —— 依赖清单
- `output/` —— 生成的 PDF 与预览图
- `.venv/` —— 虚拟环境（首次启动自动创建，勿删）

## 处理与失败行为

默认混合模式先擦除手写，再完整保留清理后的题目图像，避免 OCR 改写分数、算式或裁掉配图。括号内容和数字不会仅因其形式被清空或删除。红笔残留会根据原图颜色在本地二次清理。OCR 仅用于质量检查；若仍识别到疑似答案或题干缺损，页面会明确标出需要复核的图片和区域，不会显示为无条件成功。云端擦除失败时停止生成，页面提示失败的图片和框选编号，可重试；不会把原图当成成功白卷。每次生成使用唯一文件名，避免并发覆盖。`mode: "typeset"` 可启用实验性 OCR 重排，但不建议用于需保证题意准确的正式练习卷。

窄栏或半页题目会保留其在原始试卷上的相对字号，并自动与同页的窄题紧凑排版，避免字号过大和页面空白。

为避免把低分辨率手机截图过度放大，白卷默认按 A4 150dpi 输出；原始图片越清晰，打印效果越好。建议使用手机相机原图而非聊天软件压缩后的图片。

本地回归测试：`.venv\Scripts\python.exe -m unittest discover -s tests -v`。测试使用模拟云端，不产生云调用费用。
